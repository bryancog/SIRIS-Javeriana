\subsection{Resultados de pruebas frontend/E2E con Playwright v0.4}

La cuarta ejecución automatizada se enfocó en validar el flujo visible de usuario desde
el navegador. Las pruebas fueron ejecutadas con Playwright sobre la aplicación SIRIS,
validando carga de login, registro de usuario, autenticación, dashboard, mapa Leaflet,
filtro temporal, activación de la herramienta de polígono y cierre de sesión.
