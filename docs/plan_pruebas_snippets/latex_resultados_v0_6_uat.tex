\subsection{Resultados de prueba de aceptación de usuario UAT v0.6}

La prueba de aceptación de usuario se diseñó para validar el flujo principal del sistema
desde la perspectiva de un usuario final. A diferencia de las pruebas automatizadas
previas, esta validación se ejecuta manualmente con apoyo de evidencias visuales,
verificando que el usuario pueda acceder, autenticarse, seleccionar fechas, dibujar un
polígono, iniciar la exportación asíncrona, observar el progreso, visualizar el video,
descargar el ZIP GeoTIFF/CSV y cerrar sesión.
